# DEMIURGE - An OCAML LSP for Mohpological Source Code

> clone, cd to DEMIURGE

> opam exec -- dune build

> opam exec -- opam exec dune exec ./bin/main.exe



Dev-env SSH:

```
#25 10.31 - Port: 2222
#25 10.31 - User: vscode
#25 10.33 Forward port 2222 to your local machine and run:
#25 10.33   ssh -p 2222 -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -o GlobalKnownHostsFile=/dev/null vscode@localhost
```
